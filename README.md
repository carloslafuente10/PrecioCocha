# PrecioCocha

Base del frontend web de PrecioCocha, una plataforma en preparación para buscar y comparar precios en comercios de Bolivia, comenzando por Cochabamba.

## Requisitos

- Node.js
- npm

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.
